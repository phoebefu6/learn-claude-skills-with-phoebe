# Official course map - learn-claude-skills-with-phoebe

**Thesis:** the right Claude *skills* make any workflow drastically faster while consuming
*fewer* tokens (progressive disclosure loads context only when a skill fires). This course
teaches the highest-leverage skill stack, organized by Phoebe's 17 hub course-tracks.

Spine = **the 17 tracks**, clustered into 8 live sessions + a 17x10 reference matrix page.
Audience = public KOL + team-friendly. Attribution: **by Phoebe Fu**.

Re-verify before delivery: skills evolve. Confirm the marketplace/skill names still resolve.

## Coverage bar (80%)

Each session teaches ~80% of its skills' *working* use - when to reach for it, what it does,
the token effect, and a build-along. What stays with the source: full skill internals, the
vendor certificates, and video walkthroughs. Stated honestly on each page.

## Honest "not covered by design"

- Deep API/SDK engineering internals (pointed to Udacity + anthropics/courses).
- Every skill in Phoebe's 100+ library - only the top ~10 per track make each session; the
  rest live in the reference matrix.
- move track (yoga/tcm/drum) has the lowest dev-skill leverage - said plainly in S7.
