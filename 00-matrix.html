How to read this page

The browsable skill index

This is the index you skim when you're about to start real work and want the right specialist, not a guess. The Core Stack from Session 1 applies everywhere - it's the base layer under all 17 tracks. Each track below then lists its own top picks that sit on top of that base. Find your track, read its short table, and reach for the named skill instead of improvising. Every pick names what it does, when to use it, and its token effect - because a skill you pick on purpose spends fewer tokens than a workflow you rebuild from scratch.

💰 saves tokens 🎯 prevents rework ⚡ quality / speed multiplier
The Core Stack is inherited, not repeated Every track assumes you're already running the Core 8 - grill, route, offload, compress, verify, taste-gate. The per-track picks below are what you add on top for that specific kind of work. When in doubt, start from the Core Stack and add the track's first two picks.
